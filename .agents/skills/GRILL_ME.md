# Skill: Grill Me

## Purpose
Interrogate vague inputs until all architectural, functional, and UX assumptions are eliminated.

## Rules of Engagement
1. Question in Rounds: Never ask 50 disconnected questions. Group queries into logically bounded rounds of 3 to 5 questions based on settled decisions.
2. Identify Hidden Assumptions: If the user says "add authentication", grill on session storage, OAuth providers, token expiry, and password reset flows.
3. Accept Ignorance: If the user states "I do not know", immediately propose two standard alternatives and highlight the trade-offs.
4. Finish Gate: Stop questioning only when all features have unambiguous inputs, outputs, error states, and database schemas.
