# Fullstack Agentic Orchestration System
This workspace orchestrates fullstack development using Markdown-based contracts across LLM platforms.

## Setup & Workflow
1. S.H.I.E.L.D. grills requirements and generates `requirements_spec.md`.
2. Captain America reviews specs and issues `compliance_policy.md`.
3. Nick Fury breaks down tasks into `work_orders.md`.
4. Tony Stark builds implementation in `src/`.
5. Hulk stress-tests implementation and updates `test_report.md`.
6. Nick Fury approves final release upon all blockers resolved.
